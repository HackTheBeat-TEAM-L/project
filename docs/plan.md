# HYPEWAVE · Antigravity 초안 (Ralph 루프 부트스트랩)

확정된 서비스 로직으로 만든 Antigravity 넘김용 초안입니다.
아래 코드블록 전체를 복사해 `agy` 첫 실행에 붙여넣으세요.
**셋업 전용** — 첫 패스는 스캐폴딩·루프 러너만 만들고, 실제 기능은 이후 `while` 루프가 만듭니다.

---

```text
너는 지금부터 자율 Ralph 루프를 구동하기 위한 "셋업 담당"이다.
이번 첫 실행에서는 앱 기능을 구현하지 마라. 아래 스캐폴딩 파일과 루프 러너 스크립트만
만들고, 마지막에 내가 루프를 시작·확인할 정확한 명령어를 출력하고 종료해라.
전체 가용 시간은 약 2시간 30분이다. "동작하는 골격"을 최우선으로 확보하도록 계획하라.

════════════════════════════════════════
■ 만들 것 — HYPEWAVE (확정 로직)
════════════════════════════════════════
부스 노트북(크롬) 한 대에서 도는 단일 웹앱. 파티 관중의 환호(데시벨 스파이크)를 감지해,
그 순간의 곡과 비슷한 곡을 골라 끊김 없이 다음 곡으로 이어 트는 오토 DJ.

[확정된 서비스 루프 — 이 순서/규칙 그대로 구현]
1. 시작: 호스트가 입력란에 "음악 장르 키워드"를 입력 → 그 키워드로 첫 곡을 추천받아 재생 시작.
   재생 계정은 Spotify Premium, 최초 재생은 사용자 클릭 1회로 시작(브라우저 자동재생 정책).
2. 실시간 데시벨 측정: 마이크 수음을 측정하며 "직전 10초 롤링 평균"(베이스라인) 유지.
3. 트리거 판정: 현재 dB가 직전 10초 평균보다 +10 이상 급상승하면 함성/호응 → 트리거.
   ★+10과 10초 윈도우는 하드코딩 금지, 설정값(config)으로 뺀다.
4. 쿨다운: 트리거 후 30초간 재트리거 무시(설정값).
5. 현재 곡 파악: 그 순간 재생 중인 곡을 Spotify 재생 상태(currently-playing / SDK player_state)에서 읽는다.
   ★오디오 인식/샤잠은 절대 만들지 마라. 재생을 우리가 제어하므로 현재 곡은 이미 안다.
6. LLM 추천 2곡: 무료 LLM API에 "이 곡과 비슷한 곡 2개 추천"을 요청 → 곡 이름으로 1순위·2순위 반환.
7. 존재 검증 + URI 변환(폴백 체인): ★LLM은 없는 곡을 줄 수 있으므로 Spotify Search로 검증한다.
   - 1번곡 → Spotify Search(type=track). 결과 있으면 그 track URI 채택.
   - 없으면 → 2번곡 → Search. 있으면 채택.
   - 둘 다 없으면 → 시작 시 입력한 장르 키워드로 재추천 → Search → 채택.
   (어떤 경우에도 다음 곡이 비지 않게 보장)
8. 다음 곡 큐잉: 확정된 URI를 다음 곡으로. 현재 곡은 끊지 않고, 끝나면 자동 재생.
   ★add-to-queue는 "맨 뒤"라 바로 다음을 보장 못 함 → 앱이 자체 큐를 관리하고,
     현재 곡 종료(player_state) 시 선정 URI로 직접 play 한다.
   ★중복 방지: 현재 곡 + 직전 N곡은 추천/재생에서 제외.

[Spotify]
- Web Playback SDK로 브라우저 안에 로컬 Spotify Connect 기기(=DJ 덱)를 만들어 풀 트랙 재생.
- 필요한 스코프: streaming, user-read-playback-state, user-modify-playback-state, user-read-currently-playing.
- ★Spotify의 /recommendations·연관 아티스트·오디오 피처는 폐지되어 사용 불가. 추천은 LLM으로만 한다.

[무료 LLM 추천]
- provider는 무료·카드 불필요인 Groq(빠름) 또는 Gemini(넉넉) 중 하나. 런타임 API 키는 .env에서 읽는다.
- ★이 런타임 추천 모델은 agy 빌드 모델과 별개다(혼동 금지).
- 프롬프트는 "제목+아티스트"를 주고 "비슷한 곡 2개를 JSON [{title,artist},{title,artist}]로만" 받도록.

[UI — 최소]
- 장르 입력창(시작), 현재 곡, 실시간 dB 미터, "HYPE!" 표시, 선정된 다음 곡, 이벤트 로그.

[제약]
- 호스트 계정은 정식 Premium(Lite/Mini 불가). 마이크·SDK는 HTTPS/localhost에서만.
- 실제 관중 없이도 개발·검증되게 "가짜 dB 주입(mock) 모드"를 반드시 만들어라(아래 검증 게이트).

════════════════════════════════════════

- 루프 워커: Gemini 3.5 Flash 계열(빠르고 저렴). 루프 스크립트에서 --model 로 고정.
- 초기 스펙/작업 분해 1회에 한해 상위 추론 모델(Gemini Pro 또는 Claude) 허용, 이후 반복은 Flash로.
- 전환: 비대화형 --model 플래그, TUI에서는 /model <name>.
```

## 넘기기 전에 직접 챙길 것

- **LLM provider 확정** — Groq(속도) 또는 Gemini(넉넉) 중 하나 골라 `.env`의 `LLM_PROVIDER`/`LLM_API_KEY`에 입력. 지연 민감하니 Groq를 살짝 권장.
- **Spotify 앱 등록** — 대시보드에서 앱 생성 → client id/secret/redirect를 `.env`에 직접 입력(커밋 금지). 호스트 계정은 정식 Premium.
- **Ralph MAX** — 스코프가 있어 25~30 권장(비용 방어선).
- **가짜 dB 시퀀스용 값** — 리허설 전이라 +10은 임시. 현장에서 마이크로 실제 함성 dB를 재보고 보정하세요.

`agy` 헤드리스 플래그는 버전마다 달라, Antigravity가 `agy --help`로 직접 확인해 스크립트에 반영하도록 지시해 뒀습니다.
