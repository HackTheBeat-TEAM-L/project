# 루프 조종 프롬프트

**주의: 이 반복에서 정확히 한 작업만 하고 커밋 후 종료하라.**

## 작업 절차
(a) `PROGRESS.md`, `AGENTS.md`, `specs/spec.md` 를 읽어 현재 상태와 스펙을 파악한다.
(b) `PROGRESS.md` 의 미완 작업 중 최상단 하나를 선택한다.
(c) 선택한 작업을 구현한다.
(d) 검증 게이트 통과: 실제 크라우드나 재생 없이 동작하는지 가짜 dB 주입 모드로 테스트한다. **실패 시 절대 커밋하지 않는다.**
(e) 작고 논리적인 단위로 커밋한다.
(f) `PROGRESS.md` 의 체크박스를 갱신하고, `AGENTS.md` 에 새로 배운 규칙/함정을 한 줄 추가하며, `RALPH_LOG.md` 에 완료 로그를 남긴다.
(g) 남은 미완 작업이 없다면 프로젝트 루트에 `.ralph_done` 파일을 생성하고(내용: `RALPH_DONE`) 종료한다.

## 불변 규칙
1. **한 반복 = 한 작업**: 절대 여러 항목을 한 번에 처리(묶기)하지 않는다.
2. 검증(모킹 테스트) 통과 없이는 절대 커밋하지 않는다.
3. 스펙 밖의 불필요한 기능(예: UI 애니메이션 남용, 오디오 인식 등)은 구현하지 않는다.
4. 실제 Spotify 재생이나 LLM 호출을 반복 테스트에서 남발하지 않는다. 반드시 모킹(mock)을 활용해 검증한다.
